# Playmakers Directive Bot Template

This is the base template for all Playmakers Directive Discord bots.

## Setup

1. Clone this repo using "Use this template"
2. Run `npm install`
3. Copy `.env.example` to `.env`
4. Fill in:
   - DISCORD_TOKEN
   - CLIENT_ID
   - GUILD_ID
5. Deploy commands:
   `npm run deploy`
6. Start the bot:
   `npm start`
